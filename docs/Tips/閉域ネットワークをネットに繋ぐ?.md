## 前提条件
- 固定IPなPCsで構成されたネットワークがある(例えば192.168.77.x)
- ネット・固定IPなPCsにつながったPCがある．

## 方法
- NICを2つ用意(片方はすでにネットにつないでいる)
- もう片方を固定IPなPCsとつながるスイッチングハブにつなぐ．
- 固定IPなPCsとつないでいる方のNICの番号を`ifconfig`等で取得．(例えばenx607d0970e980など)
- 一度、ubuntuのネットワーク設定から、「インターネット共有」をクリックして、インターネット共有用の設定の雛形を作る．(例えば"Wired connection 1")
- その設定を編集する．
```
nmcli connection show
sudo nmcli connection modify "Wired connection 1" ipv4.addresses 192.168.77.1/24
sudo nmcli connection modify "Wired connection 1" ipv4.method shared
```

- 設定の再読込
```
sudo nmcli connection down "Wired connection 1"
sudo nmcli connection up "Wired connection 1"
```

これで配布されるネットワークが192.168.77.xになる．

あと、各閉域ネットワークにつながってるPCのデフォルトゲートウェイも設定してあげないといけないはず．("192.168.77.1"(橋渡しをするPCのIPアドレス)に)
